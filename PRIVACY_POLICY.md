# Privacy Policy for myDealz Filter

Version: 1.0.2  
Effective date: 2026-02-14

## Overview

myDealz Filter does not collect, sell, or share personal data.

## What data is stored

The extension stores only these local settings:

- Filter terms
- Exception terms
- Current hidden deal count
- Total hidden deal count

## How data is used

Data is used only to run the filter.

## Data transfer

No extension data is sent to external servers.

## Third-party links

The popup has optional external links. Their own privacy policies apply.

## Unofficial project notice

MyDealz Filter ist ein inoffizielles Open Source Hobbyprojekt, kein eigenes Angebot der MyDealz Webseite / Atolls Germany GmbH.
