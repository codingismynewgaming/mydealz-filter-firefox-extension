## Name

`myDealz Filter`

## Summary (DE, <= 250 chars)

Blendet auf mydealz.de automatisch Deals aus, deren Titel von dir definierte Stichwörter enthalten. Ausnahmen sind möglich, versteckte Deals werden im Popup angezeigt, und alles läuft lokal ohne Datensammlung.

## Description (DE)

myDealz Filter blendet auf `mydealz.de` Deals anhand deiner Stichwörter aus.  
Mit Ausnahmen kannst du bestimmte Treffer sichtbar lassen.  
Alle Daten bleiben lokal in deinem Browser.

## Summary (EN, <= 250 chars)

Automatically hides mydealz.de deals whose titles match your keywords. Supports exception keywords, shows hidden deals in the popup, and runs fully local in Firefox with no data collection.

## Description (EN)

myDealz Filter hides deals on `mydealz.de` using your keywords.  
Exception keywords keep selected matches visible.  
All data stays local in your browser.
